# EditFlow PRO

ვიდეო რედაქტირების პროექტების მართვის CRM სისტემა.

## ფუნქციები

- **პროექტების მართვა** - შექმენით კლიენტების პროექტები ვიდეოების ჩამონათვალით
- **ტაიმერი** - ჩაწერეთ თითოეულ ვიდეოზე დახარჯული დრო
- **Checklist** - ქვე-დავალებების მართვა
- **Deadline** - ვადების თვალყურის დევნება
- **ანალიტიკა** - დროისა და შემოსავლის გრაფიკები
- **Drag & Drop** - ვიდეოების რიგის შეცვლა
- **თემები** - 6 მზა თემა + ხელით მორგება
- **მონაცემების Backup** - ექსპორტი/იმპორტი JSON ფაილით
- **ატალღები** - Space ტაიმერისთვის, Esc მოდალის დასახურად
